## 游玩与资源检查

场景树确认两组实例化工厂立面、两张金属办公桌、一台收发电台、两盏桌灯、五把木椅、两盏工业壁灯和两组纸本已加载。调度楼内从同一起点向门内移动，关门时胶囊停在 x = −13.795，开门后到达 x = −12.300。

两次往返西南地图边缘和主街，按顺序记录的 GPU 几何数量为 1412、1419、1277、1418，纹理数量为 345、345、345、345。最后一次回到街面时，分块管理器累计回收 1534 次资源。该序列加速推进分块计时，适合验证卸载与重建，不用于评估驾驶时的帧耗时。

## 画面判断

调度楼与货运大厅的临街窗组已经有砖口厚度、窗框、玻璃和独立的饰带。货运大厅留出装卸门洞，调度楼保留交互门。西坡的旧直线台地由连续网格取代，树木落在同一高度场上。

从天际线机位仍能看到大面积平屋面。夜间云层偏亮，远处厂区与公寓的室内细节少于样板街区。这一轮验证了两栋可进入建筑、六个机位和两轮分块往返；全图逐栋精修、长时间资源压力和全章节连续通关仍待验证。

在仓库根目录执行 `node scripts/capture-coastal-quarter.cjs /tmp/saltline-review` 可重新生成更新版六个机位、性能 JSON 和往返记录。
